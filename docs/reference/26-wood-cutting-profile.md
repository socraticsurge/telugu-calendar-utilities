# Wood-cutting Source Profile

## Claim and authority

The `wood_cutting` activity is linked to `muhurta.wood_cutting`. Its authority
is B. V. Raman's *Muhurtha*, Chapter XIII, "Felling Trees," printed page 58
(PDF page 62 in the registered edition). Raman is a modern secondary
authority, not scripture.

The passage says trees should be cut while Chandra is in the last quarter so
that the timber will be strong and durable. The profile represents that
quarter as Krishna Ashtami through Amavasya and admits only those exact
Tithis.

## Chart-level condition

Raman additionally requires a dry rising Rasi, preferably aspected by a dry
Graha. The finder does not carry an authority-backed dry-sign classification
or evaluate the aspect, so this remains a visible manual check. Hard-coding an
uncited sign list would create false precision.

## Separate Panchaka rule

The activity already rejects Panchaka Nakshatras. That rule has separate
project provenance and does not inherit authority from the felling-trees
paragraph. The claim scope states this explicitly so a single citation cannot
silently validate two independent criteria.

Python and MCP publish the stable claim ID, exact Tithi list, and practitioner
check.
