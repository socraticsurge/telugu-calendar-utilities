# Historical tracking archive

This directory preserves the planning and execution record for the project
completed in June 2026. It is historical evidence, not the current maintenance
backlog.

Current work lives in the
[Telugu Calendar Utilities GitHub Project](https://github.com/users/socraticsurge/projects/2).
Each actionable item has a
[repository Issue](https://github.com/socraticsurge/telugu-calendar-utilities/issues)
for scope, acceptance criteria and discussion.

Do not add current work to these files:

- `STORIES.csv` is the closed set of ten completed feed-generation stories.
- `TASKS.csv` is its empty legacy task companion.
- `improvement-plan.md` is the June 2026 phase plan and decision snapshot.
- `DECISIONS.md` and `SESSION_LOG.md` record the retired hook-driven tracker.
- dated Markdown files retain their named maintenance-session evidence.

These files remain in place so past decisions and completion evidence stay
auditable. They should be changed only to correct the historical record or to
clarify its archival status.
