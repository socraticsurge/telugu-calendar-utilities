Use in AI assistants

Everything this site computes is also an MCP server — ask Claude or any MCP-compatible assistant for a muhurta, your family's good days, or today's Rasi Phalalu, and it calls this engine directly rather than guessing.

get_panchangamFull Panchangam for any date and city — Tithi, Nakshatra, muhurtas, eclipse, yogas
get_muhurtaOne day's auspicious & inauspicious windows — "is right now good?" (use find_muhurta to search across days)

get_special_daysNamed festivals, Ekadashi, Pournami, Amavasya, Pradosham, Ganda Moola and Eclipses for a month
get_graha_positionsAll nine grahas at sunrise — rasi, nakshatra, retrograde, and when each enters its next rasi
get_rasi_phalaluDaily reading for a rashi — every sentence rendered from computed gochara/chandrabalam/tarabalam facts
get_gocharaTransit verdicts from a janma rashi — favourable/blocked/adverse per graha with vedha, Sade Sati & Ashtama Shani flags
find_muhurtaRanked auspicious slots over coming days — good choghadiya minus all bad windows, activity-aware, with reasons
find_tarabalam_daysTarabalam & Chandrabalam — pass 1–4 birth stars (and rashis), choose the strictness, get the days favourable for everyone
list_supported_cities22 pre-configured cities with coordinates and timezone

Works with any city — pre-configured cities resolve instantly, any other city is geocoded via OpenStreetMap. You can also pass coordinates directly; the timezone is derived automatically. Supports all three calculation systems.

About

Astro Chaganti's Panchangam is a free Telugu/Vedic panchangam built for the Telugu-speaking community. It delivers daily almanac data as subscribable calendar feeds, a daily at-a-glance view, family timing tools (Tarabalam, Muhurtam), planetary transits (Gochara), and an MCP server for AI assistants. Free, open source, no account needed.

Trust & transparency

Each computation publishes its inputs, process, code owner, regression coverage, evidence state and known limits. Verification strength varies by computation and calculation system, and is stated explicitly rather than flattened into one accuracy claim.
